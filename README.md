# NewsRoom-AI-Co-Writer
An AI-powered content creation platform that helps journalists, bloggers, and media teams generate, edit, and manage articles efficiently using AI assistance.

📌 Project Overview

Newsroom AI Co-Writer is a full-stack web application built using:

Frontend: React.js
Backend: FastAPI (Python)
Database: PostgreSQL
Authentication: JWT Authentication
AI Integration: OpenAI / Gemini API

The platform allows users to:

Generate AI-powered articles
Edit and save drafts
Manage newsroom workflows
Store and retrieve articles securely
Authenticate users with secure login/signup
Search and filter content
